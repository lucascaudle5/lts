# Migrations

Forward-only SQL migrations, generated by `pnpm db:generate` (`drizzle-kit generate`) from
`src/server/db/schema.ts` and applied with `pnpm db:migrate` (`drizzle-kit migrate`, using
`POSTGRES_URL_NON_POOLING`). `meta/` is drizzle-kit's snapshot state; commit it, never edit it.

- Never edit a migration that has been applied anywhere except your own throwaway local database.
- One migration per logical change; name it for what it does (`0003_add_routine_variants`).
- Destructive changes (drop/rename column) ship in two steps: stop using it, then drop it in a later
  migration. See `docs/DEVELOPMENT_PLAYBOOK.md#schema-and-migrations`.
