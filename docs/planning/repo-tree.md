## Directory responsibilities (one line each)

| Directory        | Job                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------ |
| `src/contracts`  | Single source of truth for every shape crossing a boundary                                 |
| `src/domain`     | Deterministic life-compiler rules; pure, exhaustively tested                               |
| `src/server`     | All I/O: DB, auth, tools, approval, and the mutation layer every domain write goes through |
| `src/ai`         | Talking to models safely; nothing here writes data                                         |
| `src/app`        | Screens and thin actions                                                                   |
| `src/components` | Presentational UI                                                                          |
| `db/migrations`  | Applied schema history                                                                     |
| `docs`           | Why and how; ADRs for decisions                                                            |
| `e2e`            | The one test that proves the slice works                                                   |

Intentionally absent: `packages/`, `apps/`, `config/` package, `ui/` package, `scripts/` (seed and
eval are `pnpm` scripts pointing into `src/`), `legacy/`.
